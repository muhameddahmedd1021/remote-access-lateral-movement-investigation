# Authorized administrative baseline

The planned baseline used the known source SOC-WS01 and the existing lab.ops account on SOC-SRV01. Its purpose was to check the target identity and account through Windows interfaces, then compare session disconnect, reconnect and sign-out. The account already had target-local administration through SOC-Lab-Operators.

The [RDP case](../R02/README.md) contains the actual shared baseline episode, its pictures and original records. R01 and R02 refer to that same initial desktop sign-in, not two separate logons. No file transfer or remote command occurred during the desktop checks.
